# Marlen Alvarez | Portfolio

Portfolio personal como Desarrolladora Full Stack. Proyectos, habilidades y contacto.

## Stack

- **React 19** + **Vite 8**
- CSS vanilla (responsive con Grid y Flexbox)
- Formulario con Formspree
- Despliegue en GitHub Pages

## Secciones

- Hero
- Sobre mí
- Proyectos (ZikloLaudio, RetroDenda, MoneyLink)
- Contacto (formulario + LinkedIn, GitHub, WhatsApp)

## Scripts

```bash
npm run dev      # Desarrollo
npm run build    # Build producción
npm run preview  # Vista previa del build
npm run lint     # ESLint
```
