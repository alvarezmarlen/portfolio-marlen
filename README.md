# Marlen Alvarez | Portfolio

Portfolio personal desarrollado con React + Vite.

## Stack

- React 19
- Vite 8
- CSS vanilla (responsive con Grid y Flexbox)

## Scripts

```bash
npm run dev      # Entorno de desarrollo
npm run build    # Build producción
npm run preview  # Vista previa del build
npm run lint     # ESLint
```

## Despliegue

```bash
npm run build
```

El contenido generado en `dist/` puede subirse a cualquier hosting estático (GitHub Pages, Netlify, Vercel, etc.).
